## 2. 核心数据流

### 2.1 主要业务流程数据流向

```
分润开票审批申请提交
  → 启动流程
    → 数据初始化自动节点（FeeAllocateAutoTaskHandler: AUTOTASK_FLOW_START_DATA_HANDLE）
      → 更新状态为"审核中"
    → 供应链财务bp岗审批（人工审批 RushSignTask-fin_bp_audit）
      ├─ pass → 审批通过自动节点（AUTOTASK_AUDIT_PASS_HANDLE）
      │         → 执行开票通过逻辑
      │         → 流程结束
      └─ reject → 审批拒绝自动节点（AUTOTASK_AUDIT_REJECT_HANDLE）
                  → 更新状态为失败
                  → 流程结束
```

### 2.2 跨模块调用链路

```
[jinkoscf-workflow]                         [jinkoscf-transaction]
  FeeAllocateAutoTaskHandler
    ├─ FeeAllocateDataFacade.updateStatusAuditing()  → 更新状态为审核中
    ├─ FeeAllocateDataFacade.openBillAuditPass()     → 审批通过开票处理
    └─ FeeAllocateDataFacade.updateStatusFail()      → 审批拒绝更新状态
  FeeAllocateGlobalTaskNoticeHandler
    └─ FeeAllocateDataFacade.sendOATodo()            → 发送OA待办通知
```

## 3. 工作流执行链路

### 3.1 流程概览

| 属性 | 值 |
|------|---|
| 流程 Key | `Flow-a1a7121bb3244a1a852b0fec7552ab27` |
| 流程名称 | 分润开票审批流程 |
| 节点数量 | 6 个（最简单流程） |
| 流程定义文件 | `jinkoscf-common/.dev-standards/knowledge/procdefs/分润开票审批流程-V23.json` |

### 3.2 关键节点与监听器

| 节点 ID | 节点名称 | 监听器类 | 事件类型 | 核心逻辑 |
|---------|---------|---------|---------|---------|
| (全局) | 全局任务通知 | FeeAllocateGlobalTaskNoticeHandler | GlobalTaskNotice | 发送OA待办通知 |
| AutoTask-flow_start_data_handle | 流程启动数据处理 | FeeAllocateAutoTaskHandler | ExecutionListener(END) | 调用 `updateStatusAuditing()` 将开票状态更新为审核中 |
| RushSignTask-fin_bp_audit | 供应链财务bp岗审批 | - | 人工审批 | 财务BP岗人员审批 |
| AutoTask-audit_pass_handle | 审批通过处理 | FeeAllocateAutoTaskHandler | ExecutionListener(END) | 调用 `openBillAuditPass()` 执行开票通过逻辑 |
| AutoTask-audit_reject_handle | 审批拒绝处理 | FeeAllocateAutoTaskHandler | ExecutionListener(END) | 调用 `updateStatusFail()` 更新状态为失败 |

### 3.3 监听器详细说明

#### 3.3.1 FeeAllocateGlobalTaskNoticeHandler（全局任务通知）

| 属性 | 值 |
|------|---|
| 完整类名 | `com.lls.cloud.scf.workflow.provider.exthandler.listener.globaltasknoticehandler.feeallocate.FeeAllocateGlobalTaskNoticeHandler` |
| 文件路径 | `jinkoscf-workflow/jinkoscf-workflow-provider/src/main/java/com/lls/cloud/scf/workflow/provider/exthandler/listener/globaltasknoticehandler/feeallocate/FeeAllocateGlobalTaskNoticeHandler.java` |
| 实现接口 | `IGlobalTaskNoticeHandler` |
| 绑定节点 | 全局 |
| 核心逻辑 | 调用 `feeAllocateDataFacade.sendOATodo()` 发送OA待办通知 |
| 依赖服务 | FeeAllocateDataFacade |

#### 3.3.2 FeeAllocateAutoTaskHandler（自动节点处理）

| 属性 | 值 |
|------|---|
| 完整类名 | `com.lls.cloud.scf.workflow.provider.exthandler.listener.executionlistenerhandler.feeallocate.FeeAllocateAutoTaskHandler` |
| 文件路径 | `jinkoscf-workflow/jinkoscf-workflow-provider/src/main/java/com/lls/cloud/scf/workflow/provider/exthandler/listener/executionlistenerhandler/feeallocate/FeeAllocateAutoTaskHandler.java` |
| 实现接口 | `IExecutionListenerHandler` |
| 绑定节点 | AutoTask-flow_start_data_handle, AutoTask-audit_pass_handle, AutoTask-audit_reject_handle |
| 核心逻辑 | 1. 仅处理 END 事件；2. 根据 elementKey 分发：`flow_start_data_handle` → updateStatusAuditing(openBillSeqNo)；`audit_pass_handle` → openBillAuditPass(openBillSeqNo)；`audit_reject_handle` → updateStatusFail(openBillSeqNo) |
| 依赖服务 | FeeAllocateDataFacade |

## 4. 第三方依赖清单

| 依赖 | 说明 | 调用方式 |

## 5. 修改热点区域

| 热点文件 | 修改频率 | 说明 |
|---------|---------|------|
| FeeAllocateAutoTaskHandler.java | 高 | 自动节点处理，业务规则变更时修改 |
| FeeAllocateDataFacade.java | 高 | 封装开票审批通过/拒绝/OA通知的具体业务逻辑 |
| FeeAllocateWorkFlowConstant.java | 低 | 节点 ID 常量 |
| FeeAllocateGlobalTaskNoticeHandler.java | 低 | OA待办通知 |

## 6. 快速定位指南

| 需求 | 定位路径 |
|------|---------|
| 流程启动后做了什么 | `FeeAllocateAutoTaskHandler` → `AUTOTASK_FLOW_START_DATA_HANDLE` → `feeAllocateDataFacade.updateStatusAuditing()` |
| 审批通过后做了什么 | `FeeAllocateAutoTaskHandler` → `AUTOTASK_AUDIT_PASS_HANDLE` → `feeAllocateDataFacade.openBillAuditPass()` |
| 审批拒绝后做了什么 | `FeeAllocateAutoTaskHandler` → `AUTOTASK_AUDIT_REJECT_HANDLE` → `feeAllocateDataFacade.updateStatusFail()` |
| OA待办如何发送 | `FeeAllocateGlobalTaskNoticeHandler.notice()` → `feeAllocateDataFacade.sendOATodo()` |
| 节点 ID 常量定义 | `FeeAllocateWorkFlowConstant` 接口 |
| 流程定义 JSON | `jinkoscf-common/.dev-standards/knowledge/procdefs/分润开票审批流程-V23.json` |
| 关键 Facade 文件 | `jinkoscf-workflow/jinkoscf-workflow-provider/.../client/facade/feeallocate/FeeAllocateDataFacade.java` |
| businessId 含义 | openBillSeqNo（开票流水号） |
